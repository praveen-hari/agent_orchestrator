# Task Details (`tasks/task-details/`)

Each task gets a dedicated markdown file (for example `tasks/task-details/task-001.md`) containing:

- Overview and dependencies
- Files to create/modify
- Acceptance criteria (checkboxes)
- Technical notes and constraints
- Subtasks and checkpoints (for longer work)
- Work log (session-by-session)
- Testing notes and expected results

## Template

Use `tasks/task-template.md` as the starting point for new tasks. It’s designed to be copy/paste friendly and to keep tasks executable without extra context.
