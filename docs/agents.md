# Codestudio Agents (`.codestudio/agents/`)

The `.codestudio/agents/` directory contains agent definition files (`*.agent.md`) that describe:

- The agent’s **role** and responsibilities
- Available **tools** (as declared in frontmatter)
- **Handoffs** (pre-baked prompts that route work to other agents)
- A suggested **protocol** for sprint planning and execution

If you use these files as part of an agentic workflow, treat them as the “team playbook” that complements the task templates under `tasks/`.
