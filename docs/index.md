# Repository Documentation

This repo is a lightweight **project/sprint tracking workspace**: it contains task templates, a sprint index file, and agent configuration files used by a Codex/Codestudio-style workflow.

## What’s in here

- **Sprint tracking:** `tasks/current-sprint.yaml` is a quick index for epics, tasks, and status.
- **Task details:** `tasks/task-details/task-*.md` files are where the rich context and work logs live.
- **Templates:** `tasks/*-template.md` provide starting points for requirements, user stories, tasks, and agent logs.
- **Agent configs:** `.codestudio/agents/*.agent.md` describe roles and handoff prompts.
