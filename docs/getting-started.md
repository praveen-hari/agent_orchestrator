# Getting Started

## Build the docs locally

1. Install MkDocs:

   ```bash
   python -m pip install -r requirements-docs.txt
   ```

2. Serve docs with live reload:

   ```bash
   mkdocs serve
   ```

3. Build a static site into `site/`:

   ```bash
   mkdocs build
   ```

## Where the docs live

- MkDocs configuration: `mkdocs.yml`
- Documentation pages: `docs/`
