# Templates (`tasks/*-template.md`)

This repo includes several templates intended to standardize how work is planned and tracked.

## Task template

- File: `tasks/task-template.md`
- Use for: individual executable tasks with acceptance criteria, subtasks, and a work log.

## Requirements template

- File: `tasks/requirements-template.md`
- Use for: functional/non-functional requirements, constraints, risks, and open questions.

## User stories template

- File: `tasks/user-stories-template.md`
- Use for: user stories with acceptance criteria, edge cases, and test notes.

## Agent log template

- File: `tasks/agent-log-template.md`
- Use for: a chronological activity log across agents during a sprint.
